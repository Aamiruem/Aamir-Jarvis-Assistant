# Practice, Debugging and AIML Interview Tips

## Data Structures

Python has several commonly used data structures:
- list: ordered, changeable collection
- tuple: ordered, immutable collection
- set: unique unordered items
- dictionary: key-value mapping

```python
students = ["Aamir", "Ali", "Sara"]
marks = {"Aamir": 90, "Ali": 85}
```

These structures are heavily used in AIML for storing rows, labels, feature values, and model output.

## Debugging Techniques

When code fails, debugging is essential.

Useful habits:
- read error messages carefully
- print intermediate values
- test one small part at a time
- check variable types before operations
- keep code simple and readable

```python
x = "10"
y = 5
print(int(x) + y)
```

Type conversion is often the difference between working and failing code.

## Common Interview Questions

Typical Python interview questions include:
- What is the difference between a list and a tuple?
- How do you reverse a string?
- What is a dictionary and when is it useful?
- What is the difference between `for` and `while` loops?
- What is a function and why is it useful?
- How do you handle errors with `try` and `except`?

## Study Plan

For AIML learners, a good order is:
1. variables and data types
2. operators and comparisons
3. conditions and loops
4. functions
5. lists, dicts, sets and tuples
6. debugging and practice questions
7. then move into NumPy, Pandas, ML, and AI projects

## Final Advice

The best way to learn Python for AIML is to code daily. Do short exercises, write small scripts, and practice explaining logic clearly. In interviews, strong fundamentals matter more than memorizing advanced libraries.
