# SEO and Google Search Console

Two sites can be public:

| Site | What it is | SEO files |
|---|---|---|
| [dashboard/](../dashboard/) (Next.js) | The **landing page** (`/`), sign-in, sign-up and the dashboard | Built from [`src/lib/site.ts`](../dashboard/src/lib/site.ts): metadata, `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, the link-preview image `opengraph-image`, JSON-LD (`WebSite`, `SoftwareApplication`, `FAQPage`) |
| [frontend/](../frontend/) (React + Vite) | The Jarvis app itself | [`index.html`](../frontend/index.html) meta tags and JSON-LD, plus `robots.txt`, `sitemap.xml`, canonical and Open Graph links generated by the `seo` plugin in [`vite.config.js`](../frontend/vite.config.js) |

The landing page is the one to rank in Google: it is rendered to static HTML, has the real content
(features, how it works, FAQ) and FAQ structured data. Signed-in pages (`/dashboard/*`) are
`noindex` and disallowed in `robots.txt`.

## 1. Set the public address (at build time)

| Where | Variable | Example |
|---|---|---|
| `dashboard/.env.local`, or the host's settings (Vercel, Netlify, Amplify) | `NEXT_PUBLIC_SITE_URL` | `https://www.jarvis.example.com` |
| `frontend/.env` | `VITE_SITE_URL` | `https://app.jarvis.example.com` |
| Docker (`.env` at the project root) | `DASHBOARD_SITE_URL`, `SITE_URL` | as above |

No trailing slash. The canonical links, sitemap and preview images are made from it, so
**rebuild after changing it**.

## 2. Verify the site in Google Search Console

1. Open <https://search.google.com/search-console>, **Add property → URL prefix**, enter the address.
2. Choose **HTML tag**. Google shows `<meta name="google-site-verification" content="abc123…" />`.
3. Copy only the `content` value into `GOOGLE_SITE_VERIFICATION` (dashboard / Docker) or
   `VITE_GOOGLE_SITE_VERIFICATION` (frontend), rebuild and deploy.
4. Click **Verify** in Search Console.

(A **Domain** property verified by a DNS TXT record also works and needs no code.)

## 3. Submit the sitemap

Search Console → **Sitemaps** → enter `sitemap.xml` → **Submit**. Then use **URL inspection** on
the home page and click **Request indexing**.

## 4. Check it

- `https://your-site/robots.txt` and `https://your-site/sitemap.xml` show your real address.
- [Rich Results Test](https://search.google.com/test/rich-results) on the home page finds the FAQ.
- [PageSpeed Insights](https://pagespeed.web.dev/) for speed (the landing page is static HTML;
  the app shows a splash before its JavaScript loads, and fonts never block the first paint).
- Share the link in WhatsApp or Slack to see the preview card.

`npm run test:e2e` in `dashboard/` checks the title, description, canonical link, preview image,
structured data, `robots.txt`, `sitemap.xml` and that `/dashboard` is `noindex`.
